Come funziona. Scegli un file: questa pagina lo controlla qui, sul tuo dispositivo. Se trova un dato personale (email, telefono, codice fiscale, indirizzo, data di nascita, il nome di un alunno) non invia nulla e ti dice dove correggere. Se il controllo è superato, il file viene cifrato prima di partire: solo Claude potrà aprirlo, e solo con il codice di Clemente.

Usare l'app su un altro dispositivo

Scarica il file delle impostazioni (codice d'invio + elenco della classe) e salvalo nel Drive della scuola: mai nel Drive personale, mai per mail. Sull'altro dispositivo apri l'app e caricalo in «Prima volta su questo dispositivo». Un passo solo.

Per avere l'icona sul telefono o sul tablet: Chrome → menu ⋮ → «Aggiungi a schermata Home» (iPhone/iPad: Safari → Condividi → «Aggiungi alla schermata Home»). Sul computer: Chrome → icona ⊕ nella barra dell'indirizzo → «Installa». Su iPhone e iPad, dopo aver aggiunto l'icona, aprila e carica lì il file delle impostazioni.
